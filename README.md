## 📂 Projetos em Destaque

### [API de Gerenciamento de Tickets de Suporte](https://github.com/GabrielCNSouza/gerenciador_tickets)
API REST de nível corporativo construída em Python e FastAPI para automatizar fluxos de chamados de suporte [44, 47].
* **Por que este projeto valida minha capacidade backend?** Ele não é uma API simples. Desenvolvi aplicando **Clean Architecture** (divisão estrita em camadas de Router, Service e Repository) [49] e desacoplamento total utilizando **Protocols** e **Injeção de Dependência** [54].
* **Segurança e Banco de Dados:** Persistência robusta em **PostgreSQL** com regras estritas de integridade de dados (SQL Constraints) e blindagem contra SQL Injection via consultas estritamente parametrizadas [52, 54].
* **Funcionalidades:** CRUD completo de tickets, paginação nativa (limit/offset), filtragem dinâmica e documentação OpenAPI automática [49, 54].

### [Travel Log — Prática de Arquitetura em Camadas](https://github.com/GabrielCNSouza/travel-log)
Aplicação interativa de terminal para simulação e registro de frotas e viagens com persistência local [59].
* **Por que este projeto valida minha capacidade backend?** Em vez de jogar o código em um arquivo único como iniciantes costumam fazer, estruturei a aplicação seguindo o padrão **MVC** [63].
* **Destaques técnicos:** Domínio absoluto de Programação Orientada a Objetos (POO), herança lógica, uso de `@dataclasses` nativas do Python [64] e isolamento de persistência de dados lidos e gravados diretamente em formato **JSON** [59, 63].

### [Cliente de API de CEP](https://github.com/GabrielCNSouza/cliente_api_cep)
Programa interativo de terminal projetado para consumir e normalizar dados geográficos nacionais [41].
* **Por que este projeto valida minha capacidade backend?** Demonstra domínio prático de **integração de sistemas** e consumo de APIs externas [42, 43].
* **Destaques técnicos:** Utilização resiliente da biblioteca Requests, tratamento preventivo de falhas de conexão de rede, timeouts, quedas de servidor e normalização automatizada de inputs do usuário com mapeamento de payloads JSON complexos para objetos Python [41, 43].
